Lain is a lightweight, self-hosted permission gate for AI agents. It authenticates agents with secret tokens, enforces field-level access control, logs every request, provides a live dashboard, and lets you instantly block suspicious agents. No cloud, accounts, or subscriptions. Built for privacy and control. Open source, simple, and easy to audit.
