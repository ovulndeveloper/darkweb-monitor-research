IronClaw-Security is the frontline defense for the age of AI agentic coding platforms. Built to scan untrusted AI downloads, forks, skills, and agent workflows before they become a breach. IronClaw-Security blocks indirect prompt-injections, malicious packages, secret leakage and cross-agent injections. Every agent return is isolated, and scanned.
