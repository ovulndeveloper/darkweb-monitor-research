Weak Cipher Detector is a Python-based tool designed to analyze SSL/TLS certificates of websites and assess their security. This user-friendly script helps both technical and non-technical users quickly determine if a website's encryption is up to current security standards. Key Features: Analyzes SSL/TLS certificates of any given website
