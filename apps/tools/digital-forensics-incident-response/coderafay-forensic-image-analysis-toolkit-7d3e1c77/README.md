Web app for image forgery detection. Runs 12 published forensic techniques: ELA, Splicebuster noise analysis, double-JPEG and JPEG ghosts, copy-move, PRNU camera fingerprint, resampling, histogram, LSB steganalysis, metadata/C2PA and more. Reports what each test measured and its limits, never a black-box real-or-fake verdict. Includes demo images.
