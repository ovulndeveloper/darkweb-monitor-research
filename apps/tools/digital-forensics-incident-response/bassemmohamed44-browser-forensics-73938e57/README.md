A cross-platform browser history analysis utility built with Python's standard library. Automatically extracts browsing history from every profile across major browsers, exports clean JSON, TXT, and CSV reports, and provides advanced filtering, search, duplicate detection, browsing statistics, logging, benchmarking, and comprehensive test coverage.
