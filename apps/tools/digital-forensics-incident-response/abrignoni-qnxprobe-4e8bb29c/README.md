Read QNX6, QNX4, ETFS, EFS, QNX IFS, ext2/3/4, F2FS, FAT32, exFAT, NTFS, HFS+, APFS and the Linux flash filesystems SquashFS, JFFS2, UBI/UBIFS and YAFFS1/YAFFS2, from raw images and flash dumps: each identified by its on-disk structure, not a partition type byte, listed and extracted to a zip. No mounting, no admin rights, standard library only.
