A small, offline-first toolkit for security hygiene and recovery. Scan drives and chat exports for BIP39 seed phrases, validate and derive EVM and Avalanche X-Chain addresses without network access, then quickly triage balances via public RPCs. Includes a system-wide multi-format scanner, a Discord-focused scanner, an offline seed checker tool.
