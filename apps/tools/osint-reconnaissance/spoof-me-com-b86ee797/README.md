# Spoof Me

- **Category:** [OSINT & Reconnaissance](../../../by-category/osint-reconnaissance/README.md)
- **Type:** [plugin](../../../by-type/plugin/README.md)
- **Status:** `indexed`
- **URL:** <https://spoof-me.com/>
- **Sources:** `awesome:jivoi/awesome-osint`
- **Reviewed:** 2026-11-23

Chrome/Firefox extension that spoofs browser fingerprint signals (user agent, language, timezone, screen, hardware) as a consistent identity and flags sites that read fingerprinting APIs. Useful for keeping an investigator's real device and locale hidden.
