Mr.Holmes is an open-source OSINT tool for gathering information on domains, usernames, and phone numbers using public internet sources. It leverages Google Dorks for targeted searches and a WhoIs API for domain insights. Features include email lookup, interactive maps, and graph generation. It’s built for educational and research purposes.
