# Logibook

- **Category:** [OSINT & Reconnaissance](../../../by-category/osint-reconnaissance/README.md)
- **Type:** [directory](../../../by-type/directory/README.md)
- **Status:** `indexed`

- **Sources:** `awesome:jivoi/awesome-osint`

Trade and logistics reference covering 250 countries: 58,730 sourced entities across ports, airports, terminals, trade zones and carriers, built from the NGA World Port Index, UN/LOCODE, SMDG terminal and liner code lists, ISO 6346 container codes, UNCTAD liner shipping connectivity and World Bank port throughput. Each port page also shows the nearest airport, city and trade zone with distances. Every figure carries its source and year. Web reference only, no API or bulk download.
