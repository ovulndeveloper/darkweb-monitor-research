Point-Zero is a static OSINT web tool for analyzing open geospatial data. It visualizes military objects and military medical facilities on an interactive map using Leaflet and data from OpenStreetMap, Overpass API, GeoNames, and Wikidata. The app runs entirely in the browser with pure JavaScript, HTML, and CSS.
