# Lacis

- **Category:** [OSINT & Reconnaissance](../../../by-category/osint-reconnaissance/README.md)

Free, open-source desktop tool for Linux and Windows that maps French companies, their directors and addresses into a sourced link graph from the national company register and the BODACC, and flags patterns such as mass domiciliation or phoenix schemes. Interface in French.
