NapierOne. A Publicly Available Modern Mixed File Data Set. The data set is suitable for a variety of testing scenarios such as Ransomware testing, Malware testing, forensic testing, file compression analysis as well as many other types of testing that requires a high quality, validated and curated data sets. NapierOne contains more than 40 popular file types with 5,000 example files of each type, available for free download. The total data set contains more than 500,000 unique files
