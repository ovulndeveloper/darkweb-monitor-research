Balls is a Bitcoin solution protecting against surveillance, censorship, and confiscation. It installs Bitcoin Core to Tails encrypted Persistent Storage and makes offline-signer CryoSticks, bootable backup USB sticks, shareable synced CipherSticks and stateless CryoSticks, and codex32 master seed backups. Learn more in README.md.
