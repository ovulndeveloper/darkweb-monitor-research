A simple Xray server setup manager: VLESS (REALITY, XHTTP, Vision, WS), Trojan, VMess, Shadowsocks, Hysteria2, experimental Turnable. Manage inbounds, routing (WARP, TOR, own servers) and the camouflage site from a menu; changes are validated before going live. Adopts existing Xray setups.
