# Dark Web Exposure Monitoring Tools

## Darkwatch
- **Description**: Dark web exposure monitor watching ransomware leak sites, breach data, and onion pages
- **Platforms**: Windows ✅, Linux ✅
- **Rank**: ⭐⭐⭐⭐
- **Key Features**: Tor-based monitoring, hit scoring, remediation recommendations, desktop alerts
- **Use Case**: Organization exposure monitoring, ransomware risk assessment

## TorBot
- **Description**: Onion service crawler for data collection
- **Platforms**: Linux ✅, Windows ❌
- **Rank**: ⭐⭐⭐
- **Key Features**: Python-based crawling, metadata extraction, configurable depth
- **Use Case**: Custom dark web research crawls
