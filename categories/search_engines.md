# Dark Web Search Engines Category

## Ahmia
- **Description**: Filtered dark web search engine with clearnet accessibility
- **Platforms**: Windows ✅ (via Tor Browser), Linux ✅ (via Tor Browser)
- **Rank**: ⭐⭐⭐⭐⭐
- **Key Features**: Strict abuse filtering, .onion only indexing, API available
- **Use Case**: Safe dark web searching, research with filtering

## Torch
- **Description**: General dark web search engine
- **Platforms**: Windows ✅ (via Tor Browser), Linux ✅ (via Tor Browser)
- **Rank**: ⭐⭐⭐⭐
- **Key Features**: Large .onion index, simple .onion address, no filtering
- **Use Case**: General dark web exploration

## NotEvil
- **Description**: Privacy-focused dark web search engine
- **Platforms**: Windows ✅ (via Tor Browser), Linux ✅ (via Tor Browser)
- **Rank**: ⭐⭐⭐
- **Key Features**: Curated index, privacy-oriented, focus on legitimacy
- **Use Case**: Privacy-conscious dark web searching

## HaveIBeenPwned Integration
- **Description**: Breach data checking and monitoring
- **Platforms**: Windows ✅, Linux ✅
- **Rank**: ⭐⭐⭐⭐⭐
- **Key Features**: World's largest breach database, API, domain monitoring
- **Use Case**: Individual/company breach checking, incident response
